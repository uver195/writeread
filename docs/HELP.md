# 写读板 · 使用帮助说明（用户文档）

> 版本：v1.5.7

## 写读板是什么？

写读板是一款 **完全离线的全屏手写练字 + 语音朗读** 小工具：
- 在屏幕上用手指书写；
- 抬手后自动识别你写的内容（汉字或字母）；
- 自动组词并 **朗读**（例：写「中」朗读「中国的中」；写「A」朗读「字母 A」）；
- 读完后画布自动清空，可以继续写下一个。

识别与朗读全部在手机本地完成，**不需要联网，不需要账号**。

## 首页三个入口

打开写读板后，首页有三个分类：
- **汉字学习**：进入手写板，只识别中文汉字；
- **英文学习**：进入手写板，只识别英文字母 A–Z；
- **设置**：文本转语音、关于软件、帮助说明。

## 汉字学习怎么用

1. 在首页点「汉字学习」，进入全屏画布；
2. 用手指写一个汉字（可横屏、可竖屏，应用自动跟随手机方向）；
3. 写完一个字后 **停笔约 1.5 秒**（无新笔画）自动识别整字；
4. 识别完成后顶部短暂显示朗读内容并语音朗读，例如：
   - 写「中」→ 朗读 **「中国的中」**
   - 写「口」→ 朗读 **「口味的口」**
5. 朗读结束，画布自动清空，继续写下一个字。

> 汉字学习只认汉字：如果你写了英文字母，会提示「这是英文字母，请到英文学习书写」，不会被误读成汉字。

## 英文学习怎么用

1. 在首页点「英文学习」，进入全屏画布；
2. 用手指写一个大写的英文字母；
3. 停笔约 1.5 秒自动识别并朗读「字母 X」（如写 A → 朗读 **「字母 A」**）；
4. 朗读结束画布自动清空。

> 英文学习只认字母：如果你写了汉字，会提示「这是汉字，请到汉字学习书写」。

## 设置 · 文本转语音（v1.5.7）

写读板在**应用内**即可切换语音并调节朗读效果，**不会改动手机系统的默认语音库**，也不影响其它 App：

1. 设置页点「文本转语音」；
2. 在「语音库（引擎）」下拉里选择手机已安装的语音（中文、英文共用这一套设置）；
3. 拖动「语速」「音调」两个进度条调节朗读效果；
4. 点「测试朗读」试听，满意即已生效（设置自动保存）；
5. 想恢复默认，点底部「恢复默认（跟随系统、语速/音调重置）」即可。

> 说明：本版已去掉单独的「发音」选项，也合并了中/英文两套设置，只需选一个语音库即可。
>
> 需要安装新的语音包？点底部「如需安装语音包：打开系统文字转语音设置」去安装，装好后返回本页重新选择即可。

## 朗读句式说明

- 汉字识别 X 后，优先用「以 X 开头的最常用词 W」朗读「W的X」；生僻字无词时朗读「X字的X」。
- 英文识别字母 X 后，朗读「字母 X」。

## 关于横竖屏

- 应用默认 **自动跟随设备姿态** 切换横竖屏；
- 横竖屏切换后已写的笔画会保留，不会丢失。

## 画布什么时候清空？

- **朗读结束（或朗读失败）后自动清空**，方便连续练字；
- 如果你在朗读结束前又开始写新笔画，画布 **不会** 清空，避免误删你新写的内容；
- 界面没有清空/撤销按钮——刻意设计，让界面保持纯净。

## 没有声音怎么办？

优先在 **设置 → 文本转语音** 里换一个语音库并点「测试朗读」确认；若仍无声，再按下面检查系统 TTS：
1. 打开手机 **设置 → 文字转语音（TTS）输出**；
2. 确认选择了支持中文的语音引擎（如 Google 语音、讯飞、小米语音等）；
3. 如提示语音数据未下载，请为 **中文（简体）** 下载一次 **离线语音包**（英文朗读需英文语音包）；
4. 若某语音库（如讯飞）设为默认后仍读不出声音，多半是该引擎需要联网或缺失离线包，可在系统设置改选其它语音库（如 Google 语音、厂商语音）或补装离线包；
5. 返回并重新打开写读板即可。

**各厂商「文字转语音」入口参考**（路径可能随版本略有差异）：
- 华为 EMUI：设置 → 辅助功能 → 文本转语音
- 小米 / 红米（MIUI/HyperOS）：设置 → 更多设置 → 语言和输入法 → 文字转语音
- 三星 OneUI：设置 → 辅助功能 → 已安装的服务 → 文本转语音
- OPPO ColorOS：设置 → 其他设置 → 无障碍 → 文本转语音
- vivo OriginOS：设置 → 快捷与辅助 → 无障碍 → 文本转语音
- 魅族 Flyme：设置 → 辅助功能 → 文本转语音

首次下载语音包可能需要网络，之后朗读 **完全离线**。

## 常见问题（FAQ）

**Q：一次写多个字会怎样？**
写读板按「一个字」识别。写完一个字并朗读完后画布会自动清空；若在一个字没读完前又写新笔画，识别结果可能不准确，请等朗读完、画布清空后再写下一个字。

**Q：识别错了怎么办？**
直接重新写同一个字即可（画布清空后重写）。中文单字识别准确率约 95%，英文约 94%。

**Q：需要联网吗？**
不需要。写读板 **没有申请联网权限**，手写识别（本地 NCNN 模型）与朗读（本地语音包）全部在手机内完成。

**Q：汉字模式写英文提示去英文学习？**
这是预期设计：汉字学习和英文学习是分开的，避免互相猜写。请到对应模式书写。

**Q：如何退出全屏/关闭应用？**
从屏幕底部上滑（手势导航）或按返回键即可退出。

**Q：支持哪些手机？**
Android 7.0（API 24）及以上，覆盖 arm64 真机与 x86_64 模拟器。

## 隐私说明

- 你写的字只在手机内存中用于识别，不保存、不上传；
- 无广告、无第三方统计 SDK。
