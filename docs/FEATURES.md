# 写读板 · 软件介绍（公开发布用）

> 一款完全离线、无广告、无联网权限的安卓手写练字 + 语音朗读小工具。
> 写读板把「识别」「组词」「朗读」拆成独立的学习面板：汉字学习只认汉字，英文学习只认字母，互不猜写。

写读板是一款 **完全离线、无广告、无联网权限** 的安卓手写练字 + 语音朗读小工具。识别与朗读全部在手机本地完成，不需要网络、不需要账号、不收集任何数据。

## ✨ 核心功能

- **首页分类入口**：打开即有「汉字学习 / 英文学习 / 设置」三个清晰入口，按学习目标进入。
- **汉字学习（只认汉字）**：全屏手写，识别 3755 个 GB2312 一级常用汉字，准确率约 95%；识别后自动用「XX的XX」句式组词并朗读（中→中国的中）。写英文字母会提示去英文学习，不会误读成汉字。
- **英文学习（只认字母）**：全屏手写，识别 26 个英文字母 A–Z（基于 EMNIST，准确率约 94%）；识别后朗读「字母 X」。写汉字会提示去汉字学习。
- **分开识别，互不猜写**：每个模式只加载对应模型，彻底去掉旧版中英文级联猜字，不再出现「写汉字读成字母」或反之。
- **停笔即识别**：连续书写时不会每抬一笔就误识别，停笔约 1.5 秒后再识别整字，多笔画字也能一次写完再读。
- **朗读后自动清空**：读完一个字画布自动清空，无需任何按钮，连续练字不打断节奏。
- **文本转语音设置**：可在设置里为「中文朗读」「英文朗读」分别选择手机已安装的语音库（TTS 引擎）及发音；不设置则跟随系统 TTS。v1.5.1 起改为按「引擎」枚举，彻底解决华为等机型列不出语音库的问题。v1.5.2 起修复「选了语音库就不朗读」的死锁，并新增「测试中文/英文朗读」按钮，选完可当场验证能否出声；所选引擎不可用时自动回退系统默认并提示。
- **多厂商语音兼容**：优先使用手机自带语音包，适配华为、小米、红米、三星、OPPO、vivo、魅族等主流厂商。
- **关于软件 / 帮助说明**：设置页内置版本来源与完整使用排错文档。

## 🔒 隐私与离线

- **无联网权限**：安装后可在「应用信息 → 权限」确认，本应用不申请任何网络权限；
- 识别模型与组词词典随 App 内置，朗读使用手机本地语音包；
- 你写的字只在内存中用于识别，不保存、不上传、不收集；
- 无广告、无第三方统计 SDK。

## 🛠️ 技术亮点

| 项 | 说明 |
| --- | --- |
| 中文引擎 | MobileNetV2 + NCNN INT8 量化，3755 类，模型约 4.1MB，本地推理约 2~4ms |
| 英文引擎 | EMNIST 训练的小网络，26 类字母，模型约 0.8MB |
| 预处理 | Java 与 Python 共用同一份 C 预处理源码，识别口径一致 |
| 组词词典 | 由 jieba 常用词频表生成，覆盖约 88% 常用字 |
| 朗读 | Android 原生 TextToSpeech，可在设置中为「中文/英文」分别指定语音或跟随系统 |
| 全屏 | WindowInsetsController / systemUiVisibility 双路径，兼容 Android 7~15+ |
| 体积 | APK 约 30MB（含模型与双 ABI 本地库） |

## 📥 安装与使用

1. 下载 `写读板-v1.5.2-release.apk`，拷贝到手机安装（需允许「安装未知应用」）；
   或用电脑执行：`adb install 写读板-v1.5.2-release.apk`
2. 打开「写读板」，进入首页，点「汉字学习」或「英文学习」进入全屏画布；
3. 用手指写一个字/字母，写完停笔约 1.5 秒，自动识别并朗读；
4. 朗读结束画布自动清空，继续写下一个。

### 文本转语音设置

设置 → 文本转语音：为「中文朗读」「英文朗读」分别选择手机已安装的 **语音库（TTS 引擎）** 与发音；不选则跟随系统 TTS。
v1.5.1 起按「引擎」枚举，华为等机型的语音库也能正常列出。v1.5.2 起选完引擎可点「测试中文朗读 / 测试英文朗读」当场验证能否出声；v1.5.3 起若所选引擎（如讯飞）在第三方应用中静默失败，将自动回退系统默认语音并提示，并记忆失效引擎避免每次空等（详见应用内「帮助说明」）。

### 没有声音怎么办

到 **系统设置 → 文字转语音（TTS）输出**，确认已选引擎并为「中文（简体）」安装离线语音包（英文朗读需英文语音包）。各厂商路径见应用内「帮助说明」。
