# 写读板 v1.2.0 正式版发布

一块撑满全屏的手写板：你写一个字，它离线识别、组词、用本地语音读出来——“中国的中”“口味的口”，读完自动清空，接着写下一个。**完全离线、无广告、无联网权限、无账号**。

## 这是什么

写读板是一款面向中小学生识字、练字、正音的全屏手写 + 语音朗读安卓工具：

- 在手机屏幕上用手指书写汉字；
- 写完一个字、停笔约 1.5 秒，由本地 NCNN 神经网络离线识别（3755 个 GB2312 一级常用字，单字准确率约 95%，推理仅 2~4 毫秒）；
- 识别成功后自动用“XX的XX”句式组词并朗读，帮你同时记住读音与用法；
- 朗读结束画布自动清空，无需任何按钮，可连续练字不打断节奏。

## 核心亮点

- **沉浸全屏书写**：隐藏状态栏与导航栏，画布撑满整屏，自动跟随手机横竖屏切换，旋转不丢笔迹。
- **完全离线**：识别模型与组词词典随 App 内置，朗读用手机本地语音包，不申请任何联网权限，不收集数据。
- **停笔即识别整字**：连续书写不会每抬一笔就误识别，写完整字停笔后才识别，多笔画字（如“张=弓+长”）一次写完再读。
- **自动组词朗读**：写“中”读“中国的中”、写“口”读“口味的口”、写“长”读“长江的长”，罕见字自动回退“X字的X”。
- **朗读后自动清空**：读完一个字画布自动清空，并带“笔画数未变”校验，不会误删你新写的笔画。
- **多厂商语音兼容**：优先选用手机自带中文离线语音包，适配华为、小米、红米、三星、OPPO、vivo、魅族等主流机型。

## 下载与安装

安装包（约 31MB）：

| 文件 | 说明 |
| --- | --- |
| 写读板-v1.2.0-release.apk | 签名正式版，推荐下载 |
| 写读板-v1.2.0-debug.apk | 调试版，一般不用 |

方式一：把 APK 拷贝到手机，点击安装；提示“未知来源”时，在系统设置中允许“安装未知应用”即可。

方式二：手机连接电脑后执行：

```bash
adb install 写读板-v1.2.0-release.apk
```

文件位于：`C:\workspace\WriteRead\Handwritten\dist\`

## 三步上手

1. 打开“写读板”，进入全屏画布；
2. 用手指写一个汉字，停笔约 1.5 秒；
3. 应用自动识别并朗读，读完自动清空，继续写下一个字。

## 没有声音怎么办

写读板使用手机系统自带的文字转语音（TTS）引擎。若无声，请到 **系统设置 → 文字转语音（TTS）输出**，确认已选择支持中文的引擎，并为“中文（简体）”下载一次离线语音包，之后全程离线。各家入口：华为在“设置→辅助功能→文本转语音”，小米/红米在“设置→更多设置→语言和输入法→文字转语音”，三星、OPPO、vivo、魅族均在“辅助功能→文本转语音”附近。

## 隐私说明

- 不联网、无广告、无第三方统计 SDK；
- 不申请网络权限，可在“应用信息 → 权限”中确认；
- 你写的字只在手机内存中用于识别，不保存、不上传、不收集。

## 兼容性与已测机型

- Android 7.0（API 24）及以上，支持 arm64 真机与 x86_64 模拟器；
- 华为 PCT-AL10（Android 10）：启动、全屏、识别、朗读、自动清空均实测正常；
- 小米/红米、三星、OPPO、vivo、魅族预期兼容，差异主要在是否预装中文离线语音包，可通过系统 TTS 设置解决。

## 已知限制

- 按单字识别设计，一次写一个字，多字同屏会影响识别效果；
- 约 12% 罕见字无合适常用词，朗读回退为“X字的X”；
- 单笔画间隔超过 1.5 秒时，可能在写完一笔后触发一次识别；
- 无云备份、无多字连写、无笔迹保存功能。
