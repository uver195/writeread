# 写读板 v1.3.0 正式版发布

写汉字，它离线识别、组词、用本地语音读出来——“中国的中”“口味的口”。写英文字母，它也能识别并朗读——“字母 A”“字母 B”。读完自动清空，接着写下一个。**完全离线、无广告、无联网权限、无账号**。

## v1.3.0 新增：英文字母识别

- 新增 26 个大写英文字母（A-Z）的离线手写识别与朗读；
- 双模型级联推理：中文模型和英文模型同时运行，比较置信度选择结果，**中文识别准确率不受影响**；
- 写英文字母时朗读“字母 X”（例：写 A → “字母 A”）；
- 低置信度时提示“没看清，请重写”，不再错误朗读，减少乱识别。

## 核心功能

- **沉浸全屏书写**：隐藏状态栏与导航栏，画布撑满整屏，自动横竖屏切换；
- **离线手写识别**：中文 3755 个 GB2312 一级字（准确率约 95%）+ 英文 26 个字母（准确率约 99%），本地 NCNN 推理，2~5 毫秒；
- **自动组词朗读**：中文识别后用“XX的XX”句式组词朗读（中→中国的中），英文识别后朗读“字母 X”；
- **停笔即识别**：停笔约 1.5 秒后识别整字，多笔画字一次写完再读；
- **朗读后自动清空**：读完自动清空画布，连续练字不打断；
- **多厂商语音兼容**：适配华为、小米、红米、三星、OPPO、vivo、魅族等。

## 三步上手

1. 打开“写读板”，进入全屏画布；
2. 用手指写一个汉字或英文字母，停笔约 1.5 秒；
3. 应用自动识别并朗读，读完自动清空，继续写下一个。

## 没有声音怎么办

到系统设置 → 文字转语音（TTS）输出，确认选择了支持中文的引擎，并为中文（简体）下载一次离线语音包。

## 隐私说明

- 不联网、无广告、无第三方统计 SDK；
- 不申请网络权限，可在应用信息 → 权限中确认；
- 你写的字只在手机内存中用于识别，不保存、不上传、不收集。

## 兼容性

- Android 7.0（API 24）及以上，支持 arm64 真机与 x86_64 模拟器；
- 华为 PCT-AL10（Android 10）实测通过；
- 小米/红米、三星、OPPO、vivo、魅族预期兼容。

## 已知限制

- 按单字识别设计，一次写一个字；
- 约 12% 罕见汉字无合适常用词，朗读回退为“X字的X”；
- 英文识别仅支持大写字母（A-Z），不支持小写或数字；
- 无云备份、无多字连写、无笔迹保存功能。
