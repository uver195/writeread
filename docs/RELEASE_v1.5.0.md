# 写读板 v1.5.0

模式分离手写（汉字只认汉字 / 英文只认字母）+ 首页三入口 + 设置页（文本转语音 / 关于 / 帮助）。

## 新增与变更

- 首页三个分类入口：汉字学习 / 英文学习 / 设置
- 汉字学习只识别中文汉字；英文学习只识别英文字母；**彻底去掉旧版中英文级联猜字**
- 误写友好提示：汉字模式写英文提示「请到英文学习书写」，英文模式写汉字提示「请到汉字学习书写」
- 设置页：文本转语音（可分别为「中文朗读」「英文朗读」选择手机已安装语音，或跟随系统默认）、关于软件、帮助说明
- 文本转语音默认跟随系统 TTS 设置
- 关于软件、帮助说明内置到应用

## 安装

- 拷贝 APK 到手机安装（需允许「安装未知应用」）；
- 或用电脑执行：`adb install 写读板-v1.5.0-release.apk`
- 包名 `com.writeread.handwritten`，可覆盖升级 v1.4.0 及之前版本（同签名证书）。
